# 安装版与便携版

## 安装版：推荐长期使用

下载 `Juzhou-v1.2.0-windows-x64-setup.exe`，双击进入中文 Windows 安装向导，不需要手动解压。

1. 保存工作并关闭句轴，打开安装程序。
2. 确认安装目录与快捷方式、达芬奇菜单选项，点击「安装」。默认安装到当前用户的 `%LOCALAPPDATA%\Programs\Juzhou`，无需管理员权限。
3. 从桌面或开始菜单打开句轴。已有 SRT 可直接校对；语音转录先按 [模型配置教程](MODEL_SETUP.zh-CN.md) 下载或关联模型。

安装程序自带基础运行文件，不含模型权重。系统需安装 Microsoft Edge WebView2 Runtime；缺失时从 [微软官网](https://developer.microsoft.com/microsoft-edge/webview2/) 安装。千问语音模型的额外环境见模型教程。

### 更新、重装与卸载

- 更新时运行新版 `setup.exe`，沿用原目录。现有 `data-location.json` 数据指针、配置、文稿和模型关联不会重置；原数据目录失效时会提示并停止，不会偷偷新建空会话。
- 句轴运行中会提示先保存、关闭再安装；不会强制关闭句轴或达芬奇。
- 全新安装的用户数据默认在 `%LOCALAPPDATA%\Juzhou`。从旧 CMD 安装方式升级会沿用原有数据位置。便携版的 `data` 不会自动合并到安装版。
- Windows「设置 → 应用 → 已安装的应用」中选择「句轴 · 达芬奇字幕助手」卸载。卸载移除安装器管理的程序、快捷方式及仍属于当前安装的菜单；**配置、文稿、数据指针和模型保留**。自行添加或修改的文件可能留在安装目录中。
- 达芬奇入口在下次启动达芬奇后可见；普通账号不能写入工作流整合目录时，改用桌面或「工作区 → 脚本 → Utility → Juzhou」。不必为了独立使用而用管理员账号安装。

当前安装包未购买代码签名证书，Windows 可能提示未知发布者。请从本仓库下载，使用同页 SHA256SUMS.txt 核对文件；不要关闭系统防护。

## 便携版：解压直接用

下载 `Juzhou-v1.2.0-win32-x64.zip`，完整解压到可写目录，双击 `00-Start.cmd`。这是便携版，**不是安装向导**。

- `00-Start.cmd`：便携启动，工作数据保存在旁边的 `data`。
- `01-Install-Resolve.cmd`：保留的旧式 CMD 安装／达芬奇入口辅助工具。它会复制程序到固定目录，不是 EXE 安装版，也不提供 Windows 卸载登记。长期使用建议改用上面的 EXE 安装版。
- `02-Check-Setup.cmd`：只读检查文件与菜单路径，不代表已实际写入达芬奇。

移动时带上整个目录，包括 `_internal`、`integration` 和自己的 `data`；外部模型及音频移动后需要重新关联。安装版和便携版尽量固定使用一种，避免打开不同工作稿。
