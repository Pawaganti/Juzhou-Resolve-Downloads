- 句轴 1.2.0，构建 `1.2.0-stable.20261030`，Windows x64；完整解压后运行 `00-Start.cmd`。
- 基础应用自带运行库，需系统具备 WebView2 Runtime；千问模型的可选运行环境按模型教程配置。模型权重不包含在下载包内。

- 当前 API 面板仅支持保存配置，尚未启用云端语音调用。不要把填写成功理解为服务已连通。
- 本地识别不自动上传配音；下载模型会连接模型来源网站。提交问题前请自行检查截图和日志，避免包含私人文稿、密钥或完整工作路径。
