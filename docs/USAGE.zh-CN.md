# 使用与故障排查

## 三条常用流程

- **有文稿**：选择配音 → 导入／粘贴文稿，校对分句 → 打轴、试听、导出或写入。
- **没有文稿**：选择配音 → 转录并校对 → 生成字幕、试听、输出。

**已有 SRT 字幕**：导入 SRT → 校对文字与时间 → 写入达芬奇字幕轨道；不需要重新转录。

音频来源可选择本地音视频或达芬奇时间线。文本可导入 TXT、DOCX、RTF、Markdown、SRT、VTT；粘贴文本会整理格式。模型未配置时先看 [模型配置教程](MODEL_SETUP.zh-CN.md)。

## 日常编辑

文稿区支持原稿保护、修订对照与双向同步。字幕区支持 Shift 连选、Ctrl 加选、批量删除、撤销重做、查找替换、右键拆分合并。输入框聚焦时 Delete／Backspace 优先编辑文字。

在波形中拖动播放头试听；点击字幕定位相应片段。缩放锁定时保持当前倍率，选择字幕仅平移定位。调整边界后再次试听；低置信、未读或重叠提示需人工判断。

## 导出 SRT

点击「导出 SRT」，核对未复核、未读文稿及时间重叠提示，选择处理范围并确认文件名。默认参考配音／时间线名称并附加日期、版本编号，也可以自己改名。

「字幕文字」可选保持原文或繁体中文。繁体转换只影响输出副本，不改工作稿与时间码，不改地区用词。重叠分轨或启用定位辅助文件时会下载 ZIP，解压后取得各 SRT；定位辅助字幕不是正式内容，放置后删除。SRT 文件以毫秒记时，界面时间码可能按帧显示。

## 连接 DaVinci Resolve

1. 安装版通过 Windows EXE 向导安装后打开桌面快捷方式；便携版解压后运行 `00-Start.cmd`。便携包保留 `01-Install-Resolve.cmd` 作为辅助入口。自动／手动安装、检查及卸载见 [接入说明](RESOLVE_SETUP.zh-CN.md)。
2. 打开项目和目标时间线。若版本提供外部脚本设置，允许本地脚本连接；不要为此开启不必要的网络访问。
3. 先在副本或测试项目中取配音、写入字幕，核对目标时间线、轨道、起始时间码、数量与文本。正式项目写入前保存工程。

工作流整合安装失败时，可先用桌面快捷方式；设置菜单存在不代表 Resolve 已连接。原生字幕写入依赖宿主能力与版本，失败时仍可导出 SRT 手动导入。应用回执撤销与宿主自身撤销不是同一操作，不应假定任意后续编辑都能一键回退。

## 数据与更新

- 便携方式：`00-Start.cmd` 使用解压目录旁的 `data` 保存工作数据，不与安装版自动合并工作稿。
- 可选安装版程序：`%LOCALAPPDATA%\Programs\Juzhou`。
- 安装版默认工作数据：`%LOCALAPPDATA%\Juzhou`，包括会话、设置、日志、缓存和导出分类目录；已有自定义数据指针会继续沿用。
- 模型：程序目录下 `models`，也可以在设置中关联其他磁盘权重。
- 关闭软件不清缓存；基础设置可指定缓存位置、手动清理和保留天数，0 表示关闭自动清理。
- 更新前关闭软件并备份自己的数据目录。不要从他人电脑复制 `data-location.json`、会话、密钥或日志。

## 打不开或无法处理

| 问题 | 下一步 |
| --- | --- |
| 只有 EXE、缺 DLL | 重新完整解压，不要单独移动 EXE |
| 窗口空白／缺 WebView2 | 安装 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)，再启动 |
| 未安装模型／千问运行组件 | 按独立模型教程配置；不是输入 API Key 就能解决 |
| 音频打不开 | 检查源文件存在、可读、未损坏；换一段普通 WAV 验证 |
| 达芬奇未连接 | 确认 Resolve 正在运行、已打开时间线、脚本能力与权限可用；先导出 SRT 完成工作 |
| 数据目录丢失 | 找回原目录并修正本机 `data-location.json`，不要清空目录来“修复” |

本版没有云端语音调用，也没有自动错误上报。下载依赖和模型会连接其来源网站；本地转录不需要把配音上传到模型网站。
